WORKFLOW RETIRED

Local Product Editor has been replaced with Sanity Studio

Product management for Choicez.lk is now powered by Sanity Studio. Authorized staff can log in securely from desktop or mobile to add and edit products, upload high-resolution photos, and update availability in real-time.

Exporting JSON files and redeploying the website is no longer required. All published changes appear immediately when visitors refresh the catalogue.

To run Sanity Studio locally, run npm run studio:dev in the project root and open:
